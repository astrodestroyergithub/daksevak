How to Test API Endpoints with DakSevak

Welcome to the complete guide for testing REST APIs, GraphQL endpoints, and Webhooks using DakSevak — built by Tamojit Roy.

1

Select Method & URL

Choose HTTP method (GET, POST, PUT, DELETE) and enter the target API endpoint URL in the request bar.

2

Configure Parameters

Add query params, custom HTTP headers, Bearer tokens, or JSON payload body in the configuration tabs.

3

Send & Inspect

Click Send to trigger the request. View status codes, response times, headers, and pretty-printed JSON payloads.

Netlify Deployment Guide

Host DakSevak in under 60 seconds

DakSevak is packaged as a high-performance single-file web application (`index.html`). To host it on Netlify:

  1. Download or export this code file as index.html.
  2. Log into your Netlify Dashboard.
  3. Drag and drop the folder containing index.html directly into the Netlify deploy zone.
  4. Your API testing platform is instantly live with a secure HTTPS URL!
