# DakSevak 🚀
> A robust, lightning-fast, and fully responsive Postman clone built for modern API testing. Hosted seamlessly on Netlify.

## Features
- **Advanced Request Builder:** Support for GET, POST, PUT, DELETE, PATCH, OPTIONS, and HEAD methods.
- **Custom Headers & Params:** Dynamically add key-value headers and URL query parameters with real-time preview.
- **Request Body Editor:** Form-urlencoded, JSON, raw text, and multipart support.
- **Environment Variables:** Manage custom key-value scopes (e.g., `{{baseUrl}}`, `{{authToken}}`).
- **Response Inspector:** Inspect status codes, response time, payload size, formatted JSON/HTML preview, and raw response text.
- **Dynamic Blog Section:** Fully responsive blog articles fetched via external APIs.
- **Netlify Ready:** Pre-configured for instant static deployment.

## Deployment on Netlify
1. Download the ZIP file containing `index.html` and assets.
2. Log in to [Netlify](https://www.netlify.com/).
3. Drag and drop the extracted folder into the Netlify deployment drop zone, or link your Git repository.
4. Your API testing suite is live!
